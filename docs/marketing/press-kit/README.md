# Lyfos Press Kit

What journalists, podcasters, and analysts get when they email
press@lyfos.signorvale.com. The web mirror is `apps/marketing/press/`.

## Files in this kit

| File                                        | Purpose                                  |
|---------------------------------------------|------------------------------------------|
| `fact-sheet.md`                             | One-page company + product summary       |
| `founder-bio.md`                            | Short + long founder bios                |
| `founder-story.md`                          | Origin narrative (~600 words)            |
| `quotes.md`                                 | On-the-record quotes for any story angle |
| `talking-points.md`                         | Pre-baked angles + counter-positions      |
| `architecture-diagram.txt`                  | ASCII version of the protocol diagram    |
| `assets-checklist.md`                       | What needs to ship as binary files        |

## When sending the kit

Reply within same business day. Attach the relevant files as a single
ZIP. Always include the fact sheet, the founder bio (short), and the
specific files the journalist asked about.
